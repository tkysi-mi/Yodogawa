## 主要用語（10〜20 個）

- 勉強会: 社内で開催される学習イベント
- 候補日: 主催者が提示する開催日の候補
- 開催通知: 確定した勉強会を参加者へ知らせる配信

## アクター / 外部システム / システム境界

- アクター: 主催者、参加者
- 外部システム: 社内 SSO（認証はすべてここに委譲する）

## 中核エンティティと責務

- 勉強会: 開催情報と状態（調整中・確定・開催済み）を持つ
- 候補日: 勉強会に属し、確定日の選択肢になる

## 重要なビジネスルール

- 確定日は候補日の中からのみ選べる
- 告知配信は開催日確定後にのみ行える

## MVP では作らないドメイン範囲

- 予算管理
- 社外ゲスト管理（社内 SSO 制約のため）
