<!--
何を書くか: 現時点の MVP スコープに「入れない」と判断したアイデア・要望の backlog。

役割分担（重要）:
  - MVP スコープの取捨選択（Must / Not Now / Won't と優先順位付け）は `02-mvp-scope.md` が担う。
  - この Parking Lot は、Not Now / Won't になったアイデアや、まだ判断していない要望の「置き場」。
  - そのため優先度は厳密に決めない（変動しやすく混乱を招くため）。MVP の優先順位は `02-mvp-scope.md` を正とする。

  - アイデアを捨てずに保持し、将来の検討に備える
  - MVP スコープを軽く保つ（迷ったらここへ退避）
  - ステークホルダーとの期待値調整

特徴:
  - 機能IDなし / 優先度は緩め: ここは確定スコープではない
  - アイデア段階の機能も含めて良い

記載粒度: 実装済み機能一覧と同程度（ユーザーが認識できる機能単位）

更新頻度:
  - MVP に昇格したら `02-mvp-scope.md` へ移動し、こちらから削除
  - 新しいアイデアや要望が出たら随時追加
  - 定期的に見直し、不要なものは削除（理由は Git コミットメッセージに残す）
-->
